# Segurança e privacidade

- O repositório é novo e contém somente dados fictícios e código original de demonstração.
- Nenhuma credencial, arquivo `.env`, configuração de município ou JSON de produção deve ser incluído.
- Nenhuma chamada é feita ao SQL Server, à Betha Cloud ou a outro serviço de terceiros.
- O arquivo JSON do site foi concebido para ser público. Não o substitua por exportação operacional.
- A interface usa `textContent` para mostrar os dados, evitando interpretar texto do snapshot como HTML.
- Este demo não deve ser usado para migração real nem para decisões sobre remuneração de pessoas.
